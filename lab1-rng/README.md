# Комп’ютерний практикум №1

**«Перевірка генератора випадкових чисел на відповідність закону розподілу»**

Реалізація на TypeScript (Bun). Усі статистичні обчислення — критерій χ², λ-критерій Колмогорова,
неповна гамма-функція, EM-алгоритм — написані вручну, без зовнішніх бібліотек.

## Що робить програма

1. **Завдання 1.** Генерує 10 000 чисел за формулою `x = −(1/λ)·ln(ξ)` (метод оберненої функції)
   для λ = 0,5; 1; 2 і двох джерел ξ (вбудований `Math.random()` та власний конгруентний генератор).
   Будує гістограму частот, рахує середнє й дисперсію, перевіряє гіпотезу про експоненційний закон
   за критерієм χ². Контрольна перевірка зі зміщеним λ показує чутливість критерію.
2. **Завдання 2.** Генерує 10 000 чисел конгруентним методом `z = a·z (mod c)`, `x = z/c`
   (a = 5¹³, c = 2³¹ та ще чотири набори параметрів). Перевіряє рівномірність за χ²,
   незалежність — за критерієм кореляції, визначає період, будує діаграму розсіювання пар
   і перевіряє лінійне співвідношення, характерне для генератора RANDU.
3. **Завдання 3.** Вимірює час сортування колекції з 1 000 000 об’єктів (300 прогонів),
   ідентифікує закон розподілу затримки серед десяти кандидатів (у тому числі сумішей,
   оцінених EM-алгоритмом) і будує три генератори-імітатори, порівнюючи точність відтворення.

## Запуск

```bash
bun install
bun start        # повний розрахунок: звіт, графіки, JSON у out/
bun test         # модульні тести
bun run typecheck
```

Повний прогін триває близько двох хвилин (більшість часу — 300 сортувань мільйона об’єктів).

## Структура коду

| Модуль | Призначення |
| --- | --- |
| `src/stats.ts` | описова статистика, гамма-функція, розподіл χ² |
| `src/distributions.ts` | теоретичні закони розподілу та оцінка їх параметрів |
| `src/generators.ts` | конгруентний генератор, метод оберненої функції, табличний метод |
| `src/mixture.ts` | EM-алгоритм для суміші логнормальних складових |
| `src/goodness.ts` | критерій χ², λ-критерій Колмогорова, тести кореляції |
| `src/task1.ts`, `src/task2.ts`, `src/task3.ts` | три завдання практикуму |
| `src/charts.ts`, `src/report.ts` | побудова SVG-графіків і звіту |
| `video/` | скрипти для збирання відеопояснення роботи |
