# Комп’ютерний практикум №2

**«Об’єктно-орієнтований підхід до побудови імітаційних моделей дискретно-подійних систем»**

Реалізація на TypeScript (Bun). Алгоритм імітації за принципом найближчої події, елементи CREATE / PROCESS / DISPOSE,
багатоканальне обслуговування й маршрутизація з поверненнями. Для верифікації реалізовано формули теорії масового
обслуговування M/M/c/K і рівняння балансу потоків мережі. Генератор випадкових чисел з початковим значенням, тому
результати відтворювані.

## Що робить програма

1. **Завдання 1.** Модель CREATE → PROCESS → DISPOSE з одним пристроєм (exp(2), exp(1), черга ≤ 5, T = 1000)
   і трасуванням перших кроків імітації.
2. **Завдання 2.** Середнє завантаження пристрою U = (1/T)·∫ state dt; збіжність до теоретичного значення M/M/1/6.
3. **Завдання 3.** Модель за рисунком 2.1: CREATE → PROCESS 1 → PROCESS 2 → PROCESS 3 → DISPOSE.
4. **Завдання 4.** Верифікація: 12 варіантів зміни вхідних змінних і параметрів з автоматичною перевіркою очікуваних
   змін, порівняння PROCESS 1 з формулами M/M/1/K, ланцюг з необмеженими чергами проти мережі Джексона.
5. **Завдання 5.** PROCESS з c ідентичними пристроями, порівняння з формулами M/M/c/K.
6. **Завдання 6.** Вихід у кілька блоків з імовірностями, зокрема з поверненням у попередні; перевірка частот переходів
   і порівняння з теорією мереж Джексона.

## Запуск

```bash
bun install
bun start        # усі завдання: звіт, графіки, JSON у out/ та Звіт_КП2_Туболев.docx
bun test         # модульні тести
bun run typecheck
```

Повний прогін триває кілька секунд. Для збирання `.docx` потрібен Google Chrome (рендерить SVG-графіки в PNG).

| Файл | Вміст |
| --- | --- |
| `Звіт_КП2_Туболев.docx` | звіт з титульною сторінкою, таблицями та рисунками |

| `out/task*.svg`, `out/task*.png` | графіки |

## Структура коду

| Модуль | Призначення |
| --- | --- |
| `src/element.ts` | базовий клас `Element`, вимога `Job`, маршрути `to` і `branch` |
| `src/create.ts`, `src/process.ts`, `src/dispose.ts` | елементи моделі |
| `src/model.ts` | алгоритм імітації за принципом найближчої події |
| `src/random.ts` | генератор і закони розподілу (аналог `FunRand`) |
| `src/theory.ts` | формули M/M/c/K, рівняння балансу потоків |
| `src/tasks.ts` | шість завдань практикуму |
| `src/schemes.ts` | схеми моделей у позначеннях методички (SVG і draw.io з однієї сцени) |
| `src/charts.ts`, `src/report.ts`, `src/docx.ts` | графіки, звіт Markdown і Word |
