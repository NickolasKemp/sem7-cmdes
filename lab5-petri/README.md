# Комп’ютерний практикум №5

**«Формалізація дискретно-подійних систем стохастичною мережею Петрі»**

Реалізація на TypeScript (Bun). Алгоритм імітації стохастичної мережі Петрі з лекції 10: часові затримки з довільним
законом розподілу, кратні та інформаційні дуги, багатоканальні переходи, конфлікти за пріоритетом і ймовірністю.
Схеми й таблиці переходів у звіті будуються з того самого опису мережі, що й модель.

## Що робить програма

1. **Задача 1.** Конвеєр з п’ятьма пристроями: час перебування деталі, завантаження пристроїв, розподіл кількості зайнятих.
2. **Задача 2.** Гнучка виробнича система з трьома роботами: два способи закріплення роботів, пропускна здатність
   за різних інтервалів надходження.
3. **Задача 3.** Два мікроавтобуси: час очікування в черзі для n = 5…25, денна виручка.
4. **Задача 4.** Управління запасами холодильників: середній запас, час між продажами, що не відбулися.

## Запуск

```bash
bun install
bun start        # імітація, схеми, графіки, JSON у out/, звіт .docx і .pdf
bun test         # модульні тести
bun run typecheck
```

Повний прогін триває близько хвилини. Для PNG-версій рисунків потрібен Google Chrome, для `.pdf` — LibreOffice (`soffice`).
