# Комп’ютерний практикум №3

**«Побудова імітаційної моделі системи з використанням формалізму моделі масового обслуговування»**

Реалізація на TypeScript (Bun). Універсальний алгоритм імітації мережі масового обслуговування за принципом найближчої
події: багатоканальні СМО (зокрема з необмеженою кількістю пристроїв), обмежені черги, пріоритет вибору з черги, типи
вимог, розгалуження маршруту за ймовірністю, за пріоритетом (сталим або залежним від стану мережі) і за умовою.
Генератор випадкових чисел з початковим значенням, тому результати відтворювані.

## Що робить програма

1. **Завдання 1.** Перевірка алгоритму: мережа Джексона з багатоканальними СМО і поверненням проти аналітичного
   розрахунку; основний і резервний пристрої з розгалуженням за пріоритетом проти формул M/M/1/K.
2. **Завдання 2.** Банк для автомобілістів: вибір коротшої смуги, перешикування між чергами, втрати клієнтів,
   заданий початковий стан; 20 прогонів з довірчими інтервалами, порівняння з M/M/2/8.
3. **Завдання 3.** Приймання хворих у лікарню: три типи хворих, пріоритет у черзі, лабораторія з поверненням і
   зміною типу; час у системі за типами, інтервал між прибуттями в лабораторію, перевірка потоків і завантажень.

## Запуск

```bash
bun install
bun start        # усі завдання: схеми, графіки, JSON у out/, звіт .docx і .pdf
bun test         # модульні тести
bun run typecheck
```

Повний прогін триває близько 15 секунд. Для PNG-версій рисунків потрібен Google Chrome, для `.pdf` — LibreOffice (`soffice`).

## Структура коду

| Модуль | Призначення |
| --- | --- |
| `src/element.ts` | `Element`, вимога `Job`, маршрут: `route`, `to`, дуги `Arc` (p, priority, when, asType) |
| `src/create.ts`, `src/process.ts`, `src/dispose.ts` | надходження, СМО, вихід |
| `src/model.ts` | алгоритм імітації за принципом найближчої події |
| `src/random.ts`, `src/stats.ts` | закони розподілу; накопичувачі статистики, довірчі інтервали |
| `src/theory.ts` | формули M/M/c/K, рівняння балансу потоків |
| `src/tasks.ts` | три завдання практикуму |
| `src/schemes.ts`, `src/charts.ts`, `src/docx.ts` | схеми мереж, графіки, звіт Word |
