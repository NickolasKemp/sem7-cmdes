# Комп’ютерний практикум №4

**«Оцінка складності алгоритму імітації»**

Реалізація на TypeScript (Bun). Модель з N послідовно з’єднаних СМО і чотири розгалужені структури з тією самою
кількістю подій N + 1, побудовані на універсальному алгоритмі імітації з КП3 (код алгоритму не змінювався).
Експериментальна оцінка — час обчислення в стаціонарному режимі з точним підрахунком подій, звернень до елементів і
переглядів дуг; теоретична — формула O = ν·T·k з лекції 5.

## Що робить програма

1. **Завдання 1.** Послідовна мережа з N СМО, перевірка інтенсивності подій ν = λ·(N + 1).
2. **Завдання 2.** Час обчислення для N = 1…500; окремі серії зі зміною T і λ.
3. **Завдання 3.** k(N) = 4·(N + 2) + a + c, O(N) = O(λ·T·N²); вартість операцій методом найменших квадратів,
   порівняння теорії з експериментом.
4. **Завдання 4.** Віяло, двійкове дерево, мережа з пропуском, мережа з поверненням: L(N) з рівнянь балансу потоків,
   O(N), O(N·log N), O(N²); вплив розгалужень на складність.

## Запуск

```bash
bun install
bun start        # досліди, схеми, графіки, JSON у out/, звіт .docx і .pdf
bun test         # модульні тести
bun run typecheck
```

Повний прогін триває близько двох хвилин; час обчислення залежить від комп’ютера, тож числа у звіті змінюються від
запуску до запуску. Для PNG-версій рисунків потрібен Google Chrome, для `.pdf` — LibreOffice (`soffice`).
