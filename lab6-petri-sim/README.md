# Комп’ютерний практикум №6

**«Застосування алгоритму стохастичної мережі Петрі для реалізації моделей дискретно-подійних систем»**

Моделі на Java з бібліотекою [PetriObjModelPaint](https://github.com/StetsenkoInna/PetriObjModelPaint): мережі збираються
з `PetriP`, `PetriT`, `ArcIn`, `ArcOut`, імітацію виконує алгоритм класу `PetriSim`. Звіт, графіки і сторінку-симулятор
збирає TypeScript (Bun) з результатів Java-частини.

## Що робить програма

1. **Завдання 1.** Конвеєр з п’ятьма пристроями (завдання 1 практикуму 5) на `PetriSim`, верифікація.
2. **Завдання 2.** Управління запасами холодильників (завдання 4 практикуму 5) на `PetriSim`, верифікація.
3. **Завдання 3.** Багатопотокова обробка запитів на двох серверах зі спільною базою даних: час обробки запиту.
4. **Завдання 4.** Пакет файлів кожної мережі: текст завдання, рисунок, `.pns`, `.pnml`, Java-метод.
5. **Завдання 5.** Рівняння станів мережі завдання 3 і їх перевірка на прогонах моделі.

## Запуск

Потрібні JDK 23+ (`/opt/homebrew/opt/openjdk`, інший шлях — змінна `JAVA_HOME_23`) і зібраний редактор
`../petri-paint/petri-swing-ui/target/petri-swing-ui.jar` (`mvn package -DskipTests` у `petri-paint`; інший шлях —
змінна `PETRI_JAR`). Порівняння з практикумом 5 читає `../lab5-petri/out/results.json`.

```bash
bun install
bun start            # пакети файлів, імітація (≈ 2 хв), графіки, explorer.html, звіт .docx і .pdf
bun run report       # те саме без повторної імітації: з наявного out/results.json
bun run typecheck
```

Генератор випадкових чисел бібліотеки не має початкового значення, тому `bun start` дає нові числа в межах довірчих
інтервалів. `trainer.html` використовує числа прогону, з якого зібрано поданий звіт.
